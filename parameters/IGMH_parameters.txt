IGMH workflow parameters
========================

Software:
- Multiwfn for IGMH analysis from Gaussian formatted checkpoint files
- VMD/Tachyon for molecular and isosurface rendering

Input files used in the example workflow:
- TS3a_SP_PCM.fchk
- TS3b_SP_PCM.fchk

Fragment definitions used for both structures:
- Fragment 1: atoms 1-72
- Fragment 2: atoms 73-94

Fragment customization:
- Use command-line options for the same fragment definition in all systems:
  python run_workflow.py --fragment1 1-72 --fragment2 73-94
- Or edit parameters/fragments.csv for per-system definitions.
- Multiwfn atom ranges are one-based.
- VMD center_selection values are optional and use zero-based VMD atom indices.
- Use --auto-center-fragments only when you want VMD centering to follow the custom fragment ranges.

IGMH quantity visualized:
- delta-g_inter

Initial delta-g_inter isovalue:
- 0.005 a.u.

Surface coloring quantity:
- sign(lambda2)rho

Example shared sign(lambda2)rho color range:
- -0.05 to +0.05 a.u.

Color interpretation:
- blue: attractive interaction
- green: weak / van der Waals interaction
- red: repulsive / steric interaction

Rendering requirements:
- Same isovalue for TS3a and TS3b
- Same sign(lambda2)rho color range for TS3a and TS3b
- Same atom representation, sphere scale, bond radius, projection, visual scale, and rendering resolution
- White background
- No axes, GUI elements, or distracting shadows

Note:
Exact final VMD display settings should be taken from scripts/render_IGMH.tcl for complete reproducibility.

Current VMD/Tachyon rendering template:
- Image size: 2400 x 2400 px per panel
- Projection: Orthographic
- delta-g_inter isovalue: 0.005 a.u.
- sign(lambda2)rho color range: -0.05 to +0.05 a.u.
- Molecular representation: CPK 0.500000 0.170000 32.000000 28.000000
- IGMH material opacity: 0.60
- View: rotate x 62; rotate y -28; rotate z 34; scale 0.213
- TS3a screen translation: 0.05 -0.01 0.00
- TS3b screen translation: 0.01 0.02 0.00
